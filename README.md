# Count your bits: fingerprint benchmarking to assess broad chemical space representation
Code used to analyse and compare different molecular fingerprints.


## Preprint
This repository contains all code required to reproduce the results of the preprint ["Count your bits: fingerprint benchmarking to assess broad chemical space representation"](https://www.biorxiv.org/content/10.1101/2025.06.16.659994v3)
(will undergo more cleaning and documentation).

The used scripts can be found in the `notebooks` folder. In `src` we keep the central functions used throughout this project.

Most of the notebooks make heavy use of a Python library created within this project --> [`chemap`](https://github.com/matchms/chemap)
